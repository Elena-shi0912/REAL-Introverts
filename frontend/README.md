# MBTIx Frontend

This is the **frontend** for the MBTIx personality analysis project — a web interface that takes in user posts, sends them to a backend API for MBTI prediction, and displays the results in an interactive, responsive UI.

The frontend is built with **React (Vite)**, styled with **custom CSS**, and includes animated transitions using **Framer Motion**.

---

## 🚀 Features

- 🧩 Multi-screen flow: Intro → Input → Result  
- 💬 Dynamic input fields for multiple posts  
- 🔄 Live connection to FastAPI backend for MBTI prediction  
- ✨ Animated screen transitions (swipe-up effect)  
- 📱 Responsive layout for desktop & mobile  

---

## 🧰 Tech Stack

| Layer | Technology |
|-------|-------------|
| Frontend Framework | React (Vite) |
| Styling | Custom CSS |
| Animations | Framer Motion |
| Build Tool | Vite |
| API Integration | Fast API |

## 📦 Project Setup

### 1️⃣ Install dependencies
Make sure you have **Node.js (>=18)** and **npm** installed.

```bash
# From the frontend folder
npm install
```

### 2️⃣ Run the development server

This runs the site locally on http://localhost:5173/.

```bash
npm run dev
```

Then open:
```bash
http://localhost:5173/
```
